**original_problem_statement:**
The user wants to build a full-stack mobile e-commerce application named دار البقال (Dar El Bakkal) for shop owners. The application is designed for wholesale shopping and has four distinct user roles: Customer, Admin (Controller), Driver, and Order Collector.

**PRODUCT REQUIREMENTS:**

*   **Customer Role:**
    *   Browse and add products to the cart.
    *   Confirm and track orders.
    *   Contact the admin via WhatsApp.
    *   My Gift Today feature: Appears after the 3rd order, showing earned points.
    *   Use points to discount delivery fees.
    *   Product carousels for New Products and Discounts.
    *   Account settings (name and phone number are not editable by the user).

*   **Admin Role:**
    *   Manage products, orders, and customers.
    *   View statistics.
    *   Contact customers via WhatsApp.
    *   Set delivery locations.
    *   Send notifications to customers.
    *   View a list of customers sorted by order count.
    *   View the top 20 best-selling products of the month with profit.
    *   View customer locations on a map (using a free alternative like OpenStreetMap).
    *   Manage the points system (set customer profit percentage).
    *   Manually edit a customer's location if incorrect.
    *   Manage discounts (add/remove products from the sale list).
    *   Manage the application's interface (upload/edit banner images).
    *   General platform settings.

*   **Driver Role:**
    *   Driver login.
    *   View daily orders.
    *   Update order status.
    *   Modify an order with a reason.
    *   Send notifications to the customer.
    *   View an optimized delivery route.
    *   Generate a QR code for the gift discount.

*   **Order Collector Role:**
    *   View a list of orders needing assembly.
    *   Confirm order assembly.
    *   View a list of products needed for the next day.
    *   Handle out-of-stock products and modify affected orders.

**Additional User Requirements (added during development):**
*   Username is mandatory for registration.
*   The currency must be Moroccan Dirham (درهم).
*   The icon for the customer to view their own location should be removed from the customer interface.
*   The application should be built for both Android and iOS.
*   The initial product catalog from a provided WhatsApp link should be automatically imported.

**User's preferred language**: The user communicates exclusively in **Arabic (العربية)**. The next agent MUST respond in Arabic.
